    New experiment

    Choose a scenario; its options come from the controller's contract and the scenario catalog, through GET /api/v1/scenarios/{name}/experiment-options. The experiment waits in the queue until the controller has free Ecopath pods.

    Harvest control rules

    Add the species to regulate from the list, then fill in its rule: biomass in tonnes for the whole model area, fishing mortality per year (it can be above 1). Below the biomass limit no fishing is allowed; above the biomass base the fishing mortality is the one you set. Every species in the list is sent. The initial biomass and F come from the controller, for reference. Only the species the fisheries authority has settings for can carry a rule; the others are listed, greyed. Keep as many named configurations per scenario as you like: choose one to load it, then save your changes to it or save them as a new one.

          Species import and export

          Export downloads the whole table as CSV; it imports back as is. Import maps the file's columns onto the table's, checks the file (dry run), then applies it. Upsert adds new codes and changes existing rows in the mapped columns only. Replace makes the file the table: rows not in it are deleted, unmapped columns emptied; a code still in use cannot be deleted. Any error and nothing changes.
