## HCR decisions

- Offer only species/life stages with `hcr_eligible: true`; preselect the first eligible entry.
- Show biomass in tonnes; retain kilograms in form state and API payloads. Treat the supplied backend limits as kilograms for now.
- Apply `0 < biomass_limit_kg < biomass_base_kg <= 3,300,000,000,000` and `0 < f_max <= 100`.
- Replace temporary input caps with these protocol bounds. Keep visual ranges separate and stable during dragging; expand them for larger valid table values.
- Keep three editable numeric columns: biomass limit, biomass base and fishing mortality. The lower control point remains at zero mortality; there is no editable `f_min`.
- Keep manual entry alongside dragging. Show a reset action only when values differ from their opening defaults or copied saved values; preserve row heights when selecting entries.
- Show TAC along the red curve with an offset callout and pointer; hide it during dragging.
- Remove Configure rules/No HCR toggles. Continue without configuration submits an empty rule list.
- Keep development-only dummy thresholds pending scientific defaults; do not infer thresholds from initial biomass references.
- Keep `is_mse_run: false`. Do not infer climate identifiers or automatically map short runs to SSP2.
